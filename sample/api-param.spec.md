# APIパラメータ定義書

| 項目名 | 項目名(英名) | 型 | キー | 概要 | 補足 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| ユーザーID | user_id | uint64_t | 〇 | ユーザーを一意に識別するID。<br>APIリクエストでは必須とする。<br> | 未登録のユーザーはエラーにする。<br> |
| 表示名 | display_name | std::string |  | 画面に表示するユーザー名。 | 1文字以上64文字以内。 |
| 利用状態 | status | uint8_t |  | ユーザーの利用状態を表すコード。<br>1は有効、0は無効。<br> | 初期値は1。 |

## キー一覧

| キー | 概要 | 補足 |
| :--- | :--- | :--- |
| user_id | ユーザーを一意に識別するキー。 | UUIDから移行予定。 |
| status | 利用状態を表すキー。 | 0: 無効 / 1: 有効 |
